N8N SETUP · PRIVATE BETA

Meter an n8n workflow through Mandate.

Keep the same OpenAI or Anthropic node. Replace its base URL and provider credential with the capped Mandate key for that client.

Before starting: create the client in Mandate, store the real provider credential, set its dollar cap, and copy its mdt_live_… key.

1. Create a client credential in n8n

  1. Open the credential used by the client workflow, or create a new one.
  2. Paste the client's Mandate key into the API key field. Do not paste the real provider key.
  3. Set the provider-specific base URL below and save the credential.

OpenAI

Base URL   http://localhost:3001/openai/v1
API key    <Mandate client key from /app>

Anthropic

Base URL   http://localhost:3001/anthropic/v1
API key    <same Mandate client key>

Optional: set header X-Mandate-Tag to attribute spend (for example intake-sync). Production hosts replace localhost:3001 with your Mandate URL.

If your n8n node does not expose a base URL field, use the HTTP Request node with the same path, headers, and request body you send to the provider.

2. Run one verification call

  1. Execute the model node once with a small prompt.
  2. Confirm the node succeeds without changing its model or payload.
  3. Open Mandate and confirm the client total moves within the next polling refresh.
  4. Open the event and verify provider, model, input/output tokens, cost, status, and workflow source.

Streaming is supported. Mandate injects usage reporting when required so the final token count can be metered.

3. Handle spend-control responses

429 · CLIENT_BUDGET_EXCEEDEDThe client has reached its dollar cap. Do not retry automatically.
403 · CLIENT_KEY_KILLEDThe agency used the kill switch. Stop the branch until the key is re-enabled.

In n8n, route these statuses to a controlled stop or notification branch. Retrying a blocked request will not reach the provider.

Done when

  • The workflow runs with only the credential and base URL changed.
  • The call appears under the correct client with an exact metered cost.
  • A test cap returns 429 on the next call.
  • Disabling the key returns 403 on the next call.
